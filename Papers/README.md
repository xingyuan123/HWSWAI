# Papers explaining which features are useful
## [Physical Human Activity Recognition Using Wearable Sensors](https://www.mdpi.com/1424-8220/15/12/29858)\
Possible time domain features to consider: \
mean, median, variance, skewness, kurtosis, range, total Integral of Modulus of Accelerations(IMA), Zero-Crossings Correlation-Coefficient root mean square

Possible frequency domain features to consider: \
Discrete Fourier Transform(DFT), Power Spectral Density(PSD), Peak frequency, Entropy, DC component
